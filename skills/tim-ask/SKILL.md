# Ask 🔑

- before starting any fix or feature
  ✓ ask user to provide `idea.md`
- if `idea.md` is not prepared
  ✓ ask each section one by one

# Sections 🔑

- `Background` — what is the current situation?
- `Task` — what needs to be done?
- `Start From` — which file or screen to start from?
- `Reference` — any figma, swagger, or link?

# Output 🔑

- write `idea.md` to `.claude/temp` (if not exist)
